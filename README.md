# 안드로이드 시험 대비 노트

모바일 프로그래밍 서술형 시험 범위를 직접 정리한 학습용 웹앱입니다. 빌드 없이 정적 파일만으로 동작합니다.

- **요약 노트** — 범위별 개념, 코드 해설, 시험 포인트, 개념 그림 10개
- **생명주기 시뮬레이터** — 홈 버튼·뒤로 가기 등을 눌러 어떤 콜백이 어떤 순서로 불리는지 흐름도에서 확인
- **서술형 연습** — 32문항. 답안을 써 보고 채점 포인트로 자기 채점, 헷갈린 문제만 다시 풀기 (진행 상황은 브라우저에 저장)
- **치트시트** — 호출 순서, 코드 조각, XML 속성 모음
- `android-exam-study.pdf` — 같은 내용을 인쇄용으로 묶은 PDF

> 직접 정리한 노트이며 강의자료 원본이 아닙니다. `[보충]` 표시는 강의자료 외 보충 설명입니다.

## 로컬 실행
`index.html`을 브라우저로 열면 됩니다.

## PDF 다시 만들기
`print.html`을 Chrome으로 열어 인쇄(PDF로 저장)하거나:

```
chrome --headless=new --no-pdf-header-footer --print-to-pdf=android-exam-study.pdf print.html
```

내용 수정은 `js/content.js`, 그림 수정은 `js/diagrams.js`만 고치면 웹앱과 PDF에 모두 반영됩니다.
